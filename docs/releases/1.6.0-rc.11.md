# NX Port Studio 1.6.0 RC11

This candidate makes my wired PowerA controller work in my Mac ports, and in Nextendo mode the host now tells Nextendo which game I am playing, so friends can see me online. It also carries RC10's changes.

## Wired Switch pads that macOS does not list

My PowerA "NSW wired controller" (USB, 20D6:A713) did nothing in my ports. It is a plain USB HID gamepad. macOS's GameController framework does not list it, and the host read buttons only through GameController. The host now reads the wired Switch pads in SDL's list (20 IDs: PowerA, HORI, PDP and ZUIKI) straight from HID, without taking them away from other apps ([development notes](https://github.com/RobiiAragon/NX-Port-Studio/blob/v1.6.0-rc.11/docs/development.md)):

- Each pad gets its own player and follows Combine, `DM_PAD_MERGE`, the Controls… bindings and focus release. The Controls window lists it.
- The state reaches the game only when it changes, so the pad's constant idle reports do not override scripted input.
- If a later macOS lists such a pad in GameController, GameController's version takes over, so one pad never becomes two players.
- `DM_PAD_HID=0` turns this off.

I played Splatoon 3 with my PowerA pad. I have not tested the other 19 IDs; they come from SDL. Wireless PowerA pads pair as a Pro Controller and are unchanged.

## Nextendo: presence for games that never publish it

A friend playing on Nextendo's emulator could not see me online in Splatoon 3, although my side received their entry: online, in the same game. Splatoon 3 never publishes presence. On a console the system does that. Nextendo's developer guide asks a third-party application to post it at least every 90 seconds, as Nextendo's emulators do. In Nextendo mode, the Mac and iOS hosts now publish the game's latest declared state every 45 seconds. That state is "playing this game" until the game commits its own presence or closes its online session ([reference entry](https://github.com/RobiiAragon/NX-Port-Studio/blob/v1.6.0-rc.11/docs/reference/services.md#a-game-that-never-publishes-presence-stays-offline-to-its-friends)).

Publishing needs the OAuth `presence` permission, which sign-in now requests in the game's settings window, in Studio and on iOS. My registered application may request it, as Nextendo's consent page shows. **An account linked before RC11 must sign in again (Sign in again…) to grant it.** Until then nothing is sent. With `DM_ACCOUNT_TRACE=1` the log counts the friend snapshot (records, online, in this game) and the refresh results, without any ID, name or token.

## Leads I checked

- **120 fps in Splatoon 3.** The engine has one place that sets how far its logic steps per frame: 1.0 at 60 fps and 2.0 in its 30 fps scenes. I halved it and presented at 120 Hz, first as a cheat and then in the patched image, and the game ran at double speed. Its gameplay advances a fixed tick per frame, not by elapsed time, so 120 fps at normal speed would need generated in-between frames. I did not ship any of it.

## What I checked

- `make -C dm/host/tests pad-hid`: 48 checks (button and stick decoding, matching SDL's decoder) and 23 for the macOS reader, 0 failed, also with sanitizers. With my PowerA plugged in, `pad-hid-live` connected it as player 1 and ignored about 500 unchanged idle reports in 4 seconds.
- `nextendo-social` and its ASan/UBSan run: 421 checks, 0 failed. Studio's sign-in tests (14) request the new permission and still refuse a grant broader than the request. The renewal tests (8) pass.
- All CI checks of PR #57 passed, and the documentation tests pass.
- From this code I rebuilt my Mac ports of Link's Awakening, Super Mario Odyssey, Splatoon 2, Mario Kart 8 Deluxe, Super Smash Bros. Ultimate and Splatoon 3; each passed the host's startup check.

## Limits

I have not yet seen a presence publication succeed from my Mac, nor a friend see me in a game. Online play I have confirmed is still the Splatoon 3 Salmon Run shift (RC9's code), so RC10's UDP-socket change and Smash Quickplay remain untested. LAN and LDN remain qualified only for Mario Kart 8 Deluxe 3.0.5, and online play on iPhone is not qualified. Rebuild a port to get the host changes; updating Studio does not update an exported app.

I include source, original UI and third-party notices only. Game data, firmware, keys, personal saves and account credentials remain private.
