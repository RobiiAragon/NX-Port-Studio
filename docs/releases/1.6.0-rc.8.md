# NX Port Studio 1.6.0 RC8

I added JKSV save ZIP interchange to Studio and the native Apple port launchers. I can import a backup, export a flat JKSV ZIP, browse its files and keep the previous save as a recovery copy. On iPhone/iPad, an import is prepared from Files and applied on the next cold launch before any guest preload; exports share one committed snapshot.

I preserve original JKSV metadata when present, verify the title/save type, and preserve Horizon's case-sensitive names across Apple filesystems. I keep account and additional device saves separate. I do not synthesize a console account identity or convert encrypted save containers.

## What I checked

- Studio's full Swift suite passed: 101 PortCore and 8 Studio tests.
- The shared archive implementation passed 28 independent ZIP/restore tests normally and under ASan/UBSan, including retained previous trees, lease contention, deferred imports, recovery without rollback, APFS attribute preservation and case-colliding names.
- The complete Mac host built and validated its 1,034 HLE registrations; all 210 iPhone host source files compiled. The production iOS project also linked with synthetic embedded modules, without signing or game files; that test artifact is not an installable game.
- I exported the installed Mario Kart save through Studio's running interface and verified every exported file byte against its committed source. I also imported a synthetic ZIP through a native Mac launcher and verified the complete previous save remained in Backups. I did not replace a real game save for this test.
- I compiled the native save controls for both Apple SDKs and provided the five existing interface languages.

These checks establish the implementation and interchange format. I have not yet qualified a physical Switch restore or the new controls on an iPhone. Rebuilding a port is required; updating Studio does not update a previously exported app.

## Existing game results remain scoped

I retain the RC7 fixes and the documented Mac Mario Kart 4.0.1 completed online race.
