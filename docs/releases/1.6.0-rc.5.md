# NX Port Studio 1.6.0 — Release Candidate 5

I prepared RC5 to address Mac fullscreen pacing and to deliver Splatoon 2 calendars through the native runtime. The release tag is `v1.6.0-rc.5`; the Mac bundle is version `1.6.0`, build **22**. I still qualify each game, platform and connection path separately.

## Changes

- I keep Mac game rendering in the application's main process. The settings window and the game now share one AppKit lifecycle, instead of keeping a launcher process above a child renderer. I preserve the saved graphics settings, native resolution and MetalFX selection. Optional cloud-save synchronization uses a separate non-GUI helper with an acknowledged startup and an observed game exit.
- I added BCAT delivery for the three Splatoon 2 regional identities in the signed Nextendo catalog. I prepare calendars during export, refresh them at runtime and retain validated cached data for offline use. I validate archive bounds, paths, CRCs and content structure before exposing an immutable, read-only filesystem snapshot. The calendar ZIP itself is unsigned; I require normal HTTPS authentication and use the signed catalog to authorize the supported service identity.
- I added **Firmware → Import Miis**, a private personal-Mii library separate from firmware models. I validate the supported record formats and preserve existing game databases. This is an import foundation; I have not included the original console's Mii editor in this release.
- I isolate the passive Mac account-availability check in a short-lived instance of the same executable. This also handles the legacy file-based Keychain, where my earlier `LAContext` change alone did not prevent a wait. The child disables interactive access only for itself and returns a bounded availability/expiry result. A protected item can report unavailable without stopping local boot; explicit account operations keep their existing authorization behavior. I do not grant new Keychain access or weaken service certificate checks.

I retain the RC4 networking fixes, Xcode 27.2 / Metal 32023.922 and shader chain `a7dbbce711c3`. I preserve nxnative's authorship and license notices on the `d2a86b05ccce` engine baseline.

## What I checked

I installed Mario Kart 8 Deluxe **4.0.1** on my Mac with the primary-process fix and my normal saved settings, including MetalFX. In a roughly one-minute fullscreen sample, twelve 300-frame blocks reported **59.8–60 FPS**. I also compared window, fullscreen and window again in isolated runs. I have not repeated an online race or every game's fullscreen test with this release.

I checked BCAT archive validation, cold download, cached offline access, real native filesystem reads, SDK object lifetimes and the 128-bit digest return path, including sanitizer coverage. In my private Splatoon 2 **5.5.2 EUR** Mac test with automatic networking, I reached character creation and the rendered 3D tutorial with Spanish text, validated the calendar refresh and committed the save. The runtime sample no longer showed the old Keychain wait. I also tested the helper against real temporary Keychain ACLs and locked/expired records, including sanitizers. I have not completed the gyro tutorial or a native online match; separate graphics warnings remain open and calendars alone do not establish online compatibility.

I tested Mii formats, database persistence and Mac/iOS packaging with synthetic records. I still need to qualify a personal console export inside a game. My work on running the original firmware editor remains separate and unfinished.

I require the source checks, host/graphics fixtures, sanitizers and Mac/iOS compilation to pass before publishing the release. Synthetic tests do not replace physical game sessions. I keep earlier LAN/LDN results with Mario Kart 3.0.5 and physical Switch hardware, and the earlier Smash 13.0.5 Nextendo arena round, as separate baselines. Quickplay stability and broad Nextendo gameplay remain open; see the [coverage inventory](../nextendo-coverage.md).

## Installation and scope

I package Studio with a local ad-hoc Mac signature; it is not Developer ID notarized. I include no game, firmware, console key, account credential or personal save. Game IPAs still require the creator's Xcode team/device signing.

The new primary-process layout applies when I export or rebuild a Mac port. Updating Studio does not replace every previously exported game app automatically. I preserve each port's existing shader chain until I can validate its matching runtime or rebuild its complete pipeline.
