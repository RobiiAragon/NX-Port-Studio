# NX Port Studio 1.7.0

1.7.0 adds Animal Crossing: New Horizons to the games I have played online through Nextendo, and makes Studio a launcher for the Mac ports already installed, with one shared Nextendo session. The [games table](https://github.com/RobiiAragon/NX-Port-Studio/blob/v1.7.0/README.md#games-with-online-and-local-play) says exactly what I have tested for each game.

## What I played

| Game | Result |
| --- | --- |
| **Animal Crossing: New Horizons 3.0.3, Mac** | I opened my island with a Dodo Code, and a visitor flew in, left me a full set of tools and flew home. The two games exchanged about 16,000 datagrams directly, peer to peer, over about six and a half minutes, and the session closed cleanly when they left. ## Animal Crossing online

Each of these is a general host change that the game needed first ([game note](https://github.com/RobiiAragon/NX-Port-Studio/blob/v1.7.0/dm/games/01006F8002326000/README.md)):

- **Play-history key.** Opening an island asks `friends` for a play-history registration key, and the host signed one only with a keyring imported from firmware. Without it the call failed, and the game cancelled hosting 20 ms after its NAT check, so Resetti reported a connection error. With no keyring the host now returns the key unsigned, as [ACNHRecomp](https://github.com/Nycolazs/ACNHRecomp) (MIT) does; only the visitor's play-history entry is lost.
- **Push notifications.** `npns:u` is served as a console that no push notification reaches; the game aborted when its connection failed.
- **Parental controls** answer as a console with no restriction, and **the proxy query** answers "no proxy" on an accepted network.
- **TLS.** The island API's self-signed certificate is pinned in the public Nextendo contract, and a NEX secure server named by its address keeps its CA-verified name.
- **Accounts without a BAAS ID** use the PID, as ACNHRecomp does, and friend lists then use it too.

## Studio

- **Library.** A home-menu page that launches the Mac ports in /Applications and ~/Applications: large tiles, most recently played first, keyboard and full screen, and a friends screen with best friends, requests and adding a friend by friend code. Every port still runs without Studio.
- **Nextendo agent.** A background agent shares one Nextendo session with every Mac port, so ad-hoc ports stop asking for Keychain access after a rebuild, and a sign-out reaches open games. It carries the friends and presence requests, can notify when a friend comes online or sends a request, and Studio's Friends panel accepts or declines requests. I accepted a friend request from Studio.
- A port that reaches Nextendo through its service profile alone now also gets the launcher's **Sign in with Nextendo**.
- Friend lists fill on older SDK builds (Mario Kart 8 Deluxe 4.0.1, Splatoon 2, Smash, Super Mario Odyssey).

## Diagnostics

- `DM_NEX_TRACE=1` logs each NEX call a TLS stream carries (protocol, method, call ID, result), never its parameters. `DM_NET_TRACE` names each peer by kind and port, prints the service name each lookup asked for, and puts a millisecond clock on every line; level `2` of both also prints the guest's call stack.

## What I checked

- The host, TLS, network and friends tests, including ASan and UBSan, and the documentation tests; the CI of each pull request.
- My Animal Crossing Mac port rebuilt from this code, played as above.

## Limits

- Animal Crossing: I have not yet visited someone else's island, and I have not played it online on iPhone.
- Online play on iPhone is still unqualified for every game, and LAN and LDN are qualified only for Mario Kart 8 Deluxe 3.0.5.
- Studio has a local ad-hoc signature and is not notarized. iPhone exports use the creator's own Xcode signing.
- **Rebuild a port to get these changes;** updating Studio does not update an exported game.

I include source, original UI and third-party notices only. Game data, firmware, keys, personal saves and account credentials remain private.
