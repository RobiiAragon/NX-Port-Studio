# Upstream provenance

NX Port Studio is independently developed from [seedds/nxnative](https://github.com/seedds/nxnative).

The current engine snapshot incorporates [seedds/nxnative `4a1f68301877`](https://github.com/seedds/nxnative/commit/4a1f68301877d0556237e7570eea04667d1b21b2). This synchronization brings 349 upstream commits after the shared engine baseline [`4639c5114cbb`](https://github.com/seedds/nxnative/commit/4639c5114cbb8a8f250645941fa3a25c1ba08cc6), preserving Studio’s independently developed backend, signing, resource, control and network extensions.

The earlier export named `05715be61396` as its baseline. That was a local pre-export revision containing seven project commits after the shared upstream ancestor; it was not the upstream main revision. The current provenance separates those histories explicitly. The [upstream README at the synchronized revision](https://github.com/seedds/nxnative/blob/4a1f68301877d0556237e7570eea04667d1b21b2/README.md) documents upstream’s own results.

The original MIT notice, `Copyright (c) 2026 seedds`, is preserved in [LICENSE](LICENSE). See [CREDITS.md](CREDITS.md) for additional project and dependency attribution.

The upstream screenshot gallery is not copied into this repository. Upstream game-compatibility counts describe the engine's own documented baseline; they are not claims that NX Port Studio has independently validated all those games or their online modes.
