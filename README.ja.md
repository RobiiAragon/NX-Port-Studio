**私は、自分で所有するNintendo SwitchのゲームファイルからApple向けのネイティブアプリを作成できるNX Port Studioを開発しています。** macOS用の作業環境で、リソースの準備、ビルド、コントローラー設定、XcodeによるiPhone/iPadアプリの署名を行えます。

私の独立プロジェクトは[seeddsのnxnative](https://github.com/seedds/nxnative)を基盤としています。元のエンジンの作者、MITライセンス、著作権表示を保持しています。[クレジット](CREDITS.md)と[ライセンス](LICENSE)をご確認ください。

## 主な機能

- ZIP/7z、サブフォルダ、大文字の拡張子を認識し、展開範囲と整合性を検証します。既知のビルドエラーには5言語で対処手順を表示します。
- ゲームごとのフォルダーに本編、更新データ、DLCをまとめ、実際のビルド進行状況を確認できます。
- iOS向けの出力はXcodeで署名し、検証してから成功と判定します。
- 自分の本体から取得したMiiモデル、フォント、証明書などのリソースを読み込めます。
- 私は**ファームウェア → Miiを読み込む**に個人のMiiライブラリを追加しました。描画モデルとは別に保存します。合成データで形式、永続化、Mac/iOSへの組み込みを検証しましたが、自分の本体から書き出したMiiのゲーム内検証は未実施です。[形式と制限](docs/reference/services.md#personal-mii-imports-are-separate-from-firmware-model-archives)を参照してください。
- OSと機器が公開している機能に応じて、ボタン割り当て、モーション、振動を利用できます。
- ネイティブのネットワーク処理、LAN/LDNの検出、実験的なNextendo連携を実装しています。
- iPhone/iPad上でNextendoの連携、アプリのキーチェーンへの保存、ゲームとサービスの要件確認を行う画面を備えています。

私はビルド画面に加え、エンジンのHorizonソケット、HLEの待機処理、TLS検証、アカウント、Joy-Conの処理も拡張しています。動作可否はゲーム、更新バージョン、端末によって異なります。

## 検証状況

| 項目 | 確認できたこと |
| --- | --- |
| Mac ↔ SwitchのLAN | 以前のMacビルドを使い、私の実機SwitchとMario Kart 8 Deluxe 3.0.5のレースを完走しました。現在の候補ビルドではルーム作成とホストのルール画面を確認しましたが、レースは再検証していません。 |
| iPhone ↔ SwitchのLAN | どちらをホストにした場合も、相手がルームに参加できることを私が確認しました。iPhoneでのレース完走はまだ確認していません。 |
| LDN・ローカル無線 | 10月31日、私はMac/iOSのネイティブ版と実機SwitchでMario Kart 3.0.5のLAN・LDNプレイを確認しました。同期前のポートでの結果であり、新エンジンは再検証が必要です。IP LDNには対応モジュールが必要です。 |
| Nextendo | 私はアカウント連携に加え、**Mac版Smash 13.0.5で実際の専用部屋の1ラウンド**を確認しました。サービスの特定証明書も明示的に許可しました。クイックプレイ、他のゲーム、iOSのオンライン動作を検証できた結果ではありません。 |
| Android・Windows | Apple向けの安定化後に取り組む予定です。私の配布ビルドはなく、ARMとx86にはそれぞれ開発が必要です。 |

ポートは接続サービスを自動で有効にします。別のモード選択や再起動は不要で、ゲーム内でオンライン、ローカル通信、LANを選べます。Nextendoの設定は独立しており、オンライン認証情報がなくてもローカルプレイを開始できます。ネットワーク無効化と任意の検出先アドレスは詳細設定に残ります。

LANではゲームのバージョンを揃え、同じローカルネットワークに接続してください。ネットワーク自体にインターネット接続は必須ではありません。LDNのIPブリッジには本体側の対応モジュールが必要で、ゲームに搭載されたLANモードとは別の仕組みです。

2026年10月31日、私は5つの本番サービスとのネイティブTLSハンドシェイクを確認しました。一部のNEX・認証サービスでは証明書の問題が残っています。全58件のカタログ、62の地域別設定、22のビルド別パッチ計画を組み込みましたが、ほかのネイティブオンライン対戦はまだ検証していません。私が検証したMario Kart 3.0.5はサービスが要求する4.0.1を満たしません。[対応状況の詳細](docs/nextendo-coverage.md)を参照してください。

## はじめに

StudioにはApple silicon搭載Mac、macOS 14以降、Swift 6に対応したXcodeが必要です。ゲームファイルと本体のキーは自分で用意します。現在のiOSターゲットはiOS/iPadOS 26と対応ハードウェアです。ゲームによっては、さらに新しいmacOSやMetalが必要です。

リポジトリ内で次を実行します。

    cd macOS/NXPortStudio
    swift test
    swift run NXPortStudio

Studioで環境を準備し、ゲームのフォルダーとprod.keysを選び、MacまたはiPhone/iPadを指定します。iOSではXcodeのチームとペアリング済み端末を設定してください。IPAは署名と検証の完了後に成功となり、Appleのアカウントや有効期限の制約が適用されます。

私の公開リポジトリにはソース、ツール、Studioの画面を含めます。ゲーム、本体キー、ファームウェア、アカウント情報、セーブデータ、Nintendoの画像は含めません。

Mac向けのポートは**アプリケーション**に直接インストールされます。一時的なエンジン、展開データ、ビルド生成物は、成功時も失敗・キャンセル時も削除されます。更新時は新しいアプリを検証してから同じゲームのポートを置き換え、セーブデータと設定は保持します。iOSのXcode署名フローは引き続き利用できます。
